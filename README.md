# 如东小棚虾 · 成本利润测算模型

租棚模式下的南美白对虾小棚养殖测算工具，单文件 HTML，双击即用，无需安装、无需联网。

- **工具**：`如东小棚虾成本利润测算.html`
- **版本**：2026-11-25_V2（日期制，同日多版加 _V2）
- **适用**：江苏如东及周边（盐城、通州湾）小棚模式；租棚经营；单棚 350–500㎡、放苗 5–8 万尾

> 本仓库是本项目唯一的权威位置。任何修改都在这里进行，并在 `MEMORY.md` 记录变更。

---

## 一、工具能做什么

| 模块 | 能力 |
| --- | --- |
| 参数录入 | 棚数、茬数、单棚面积；放苗量、苗价、回捕率、规格；料比、料价、电费、动保、人工、折旧、捕捞、杂费、资金利率 |
| 租金核算 | 三种口径：按㎡（面积 × 元/㎡/年）、按棚长（米 × 元/米/年）、直接填年租金，自动折算到每茬、每斤 |
| 锅炉加温 | 常温 / 燃煤 / 生物质 / 天然气 / 电锅炉 / 直接填；燃料用量 × 单价 + 设备租金，自动折算每斤成本与「需多卖」溢价 |
| 风险建模 | 按成功率、按失败棚数、或逐棚录入实际出虾量（售价可单独覆盖） |
| 结果 | 总成本/收入/净利、单棚净利、斤虾成本与利润、净利率、ROI、亩产、综合均价 |
| 盈亏平衡 | 保本虾价、保本单棚产量、保本成功率、安全边际、失败一棚需几棚填补 |
| 敏感性 | 虾价 × 成功率（逐棚模式下为虾价 × 产量系数）利润矩阵热力图 |
| 显示口径 | 单茬 / 全年一键切换；KPI、成本表、图表全部跟随，全年口径下棚租不重复分摊 |
| 方案记忆 | 自动记住上次录入；可命名保存多套方案、随时载入、删除、导出/导入 JSON |

## 二、快速上手

1. 双击 HTML，浏览器打开。
2. 先改 **棚租核算**：填单棚面积和元/㎡/年（或按棚长填元/米/年），年租金自动算出。
3. 改 **产出参数**：放苗量、回捕率、出虾规格 → 自动推算单棚产量（也可勾选直接指定产量）。
4. 填 **成功率**（或直接填失败棚数），再填虾价与各项成本。
5. 看下方「盈亏平衡」和「利润矩阵」，判断当前参数能不能干、安全边际有多厚。
6. 用结果区顶部的「单茬 / 全年」开关切换视角：单茬看一季赚多少，全年看一年总账（棚租只计一次）。
7. 调好的参数点「保存当前参数」命名存档，下次从列表一键载入。

参数会实时写入浏览器 localStorage，换电脑或清缓存后用「导出 JSON」备份、再「导入」恢复。

## 三、成本结构（默认基准情景）

单棚 400㎡、放苗 7 万尾、回捕 72%、30 头、产量 1680 斤、棚租 5000 元/年（12.5 元/㎡/年）、两茬分摊：

| 项目 | 元/棚/茬 | 元/斤 | 占比 |
| --- | --- | --- | --- |
| 饲料（料比 1.15、9800 元/吨） | 9,467 | 5.64 | 53% |
| 棚租（5000 ÷ 2 茬） | 2,500 | 1.49 | 14% |
| 人工（1 人管 30 棚） | 1,200 | 0.71 | 6.7% |
| 苗种（130 元/万尾） | 910 | 0.54 | 5.1% |
| 电费 | 900 | 0.54 | 5.0% |
| 捕捞运输（0.5 元/斤） | 840 | 0.50 | 4.7% |
| 动保药品 | 800 | 0.48 | 4.5% |
| 折旧维修 | 600 | 0.36 | 3.4% |
| 资金成本（6% × 4 个月） | 350 | 0.21 | 2.0% |
| 杂费 | 300 | 0.18 | 1.7% |
| **合计** | **17,867** | **10.64** | **100%** |

含 80% 成功率的失败棚摊销后，实际斤虾成本约 **11.9 元/斤**，保本虾价约 **12.2 元/斤**（30 头、1680 斤口径）。

## 四、几个必须记住的判断

1. **饲料是第一位**，占成本一半。料比每降 0.1，单棚省约 820 元；1.25 降到 1.10，一棚省 1,230 元。
2. **棚租是纯沉没成本**，租棚没有资产增值。租金从高峰 12,800 跌到 5,000，单茬省 3,900 元，等于每斤成本降 2.3 元——这是当前最大的红利，值得花最多精力谈。
3. **失败棚只按「浮动成本」折减**：苗款、租金、人工、折旧全额沉没，只有饲料、动保、电、加温、捕捞按比例（默认 50%）计。这是很多人算错的地方。
4. **锅炉是买时间**：加温成本 ÷ 产量 = 每斤必须多卖的价差。2.2 吨煤 2,090 元 / 1,680 斤 = 1.24 元/斤，抢不到这个价差就是白烧。
5. **成功率的价值是非线性的**：17.5 元行情下，正常棚赚 1.15 万、失败棚亏 1.02 万，一棚失败几乎抵掉一棚利润；14 元行情下，一棚失败要 1.4–2 棚来填。

## 五、数据来源与口径

- 产量 / 料比 / 成功率：海大农牧 2025 年秋虾如东塘头调研（通州湾 2100 斤、料比 1.1、成功率 70%；环农光荣 1600 斤、1.2、80%；栟茶洋口 1900 斤、1.1、85%）。
- 虾价：2026 年 9–10 月如东小棚报价，20 头 23–25 元/斤、30 头 17–18.5、40 头 14–15。
- 棚租：3000–8000 元/棚/年（2024 年后回落），高峰期 1.2–1.5 万/棚（约 320 元/米）。
- 饲料：小棚虾料 9000–11000 元/吨；投料机案例料比 1.08 vs 人工 1.16。
- 失败棚案例：150–120 头爆棚，产量 600–700 斤、虾价 5–6 元，累计投入 11,145 元，净亏约 7,600 元。

**口径提醒 1**：工具里的「斤虾成本」是含失败棚摊销的总成本 ÷ 总出虾量，不是单棚正常成本。只算后者会把成本低估 1–1.5 元/斤。

**口径提醒 2**：棚租一年一付，工具先把年租金按茬数摊到每一茬（单茬棚租 = 年租金 ÷ 茬数）。所以默认的「总成本」是**单茬**口径，不是两茬合计。切到「全年」后所有金额 × 茬数，棚租正好还原为一年全额。虾价、单产、斤虾成本、保本价始终是“每茬每斤”口径，不随开关变化。
